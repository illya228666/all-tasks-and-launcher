# Классический Сумрак и готические руины

Основной вариант `sumrak` загружает именованные клипы из `Resources/sumrak/bundle.json`. Вариант `sumrak-chibi-v2` продолжает использовать свой прежний комплект. Размер внутри Launcher — прежний; на рабочем столе стоящий персонаж занимает 20% физической высоты рабочей области монитора. Launcher работает в PerMonitorV2, прозрачные окна не масштабируются повторно через AutoScale.

## Просмотр

- `Launcher.Pet.Windows/Resources/sumrak/preview.html`: 24 клипа, шляпа/без шляпы, три фона, скорость и опоры.
- `Launcher.Pet.Windows/Resources/sumrak/renderer-review.html`: GIF последовательности из фактического PetWorld/GDI renderer и снимки экологического цикла.
- `Launcher.Pet.Windows/Resources/ruins/gothic/preview.html`: каталог, эффекты и три длины модульной площадки.
- `dotnet run --project Launcher -- --ruins-preview`: интерактивный просмотр настоящего мира. `M` меняет размер мира; `D` показывает геометрию, `E` вызывает физическое восстановление, пробел приостанавливает, Esc закрывает.

HTML открывается локально без сервера. Подписи и элементы проверки существуют только в просмотре ресурсов. Рабочий стол не получает панелей обучения.

## Производственный комплект

Мастер имеет шесть опорных поз: фронт, три четверти и профиль, со шляпой и без неё. Исходный классический кадр хранится в `references`. Художественные исходники созданы встроенным imagegen. Сохранены точные промпты действий, исходные листы и реестр генераций `production-jobs*.json`.

Каждое действие содержит `hat` и `no-hat`: отдельные PNG, прозрачный лист и GIF. `source/selection.json` связывает действие с принятым художественным листом; `source/hat` и `source/no-hat` сохраняют исходник, промпт, сетку и результаты обработки. Отдельные папки с суффиксами `correct`, `nohat` и исходные неудачные листы оставлены для истории производства; приложение их не загружает.

Общий `character-scale-profile.json` фиксирует холст 768×768 и обработку края. Все кадры переводятся к общей линии стоп 711. Разрешены перенос и единое преобразование разрешения всего листа; отдельные кадры не растягиваются. `export-checks.json` содержит 600 записей опор и границ прозрачного силуэта. Число PNG подтверждает комплектность, но само по себе не подтверждает качество движения.

В `bundle.json` заданы длительности, циклы, фазы и отдельные опоры обоих вариантов: стопы, голова, шляпа и предмет. Результат подбора/размещения принадлежит системе жизни и по-прежнему наступает через две секунды. Завершающий жест продолжается после фактического изменения мира. Наблюдение использует все 12 поз перед зачётом; захват и выход при переносе сохраняют предмет в занятой руке. Во время переработки видимый предмет уменьшается.

Кадры загружаются отдельно с LRU кешем до 128 MiB, включая альфа-маски. В сборку попадают runtime PNG и JSON, без мастер-листов и источников. Большой атлас новой версии не создаётся.

Готический каталог включает 12 площадок, четыре арки/колонны, три моста, три корня, восемь декоративных объектов, восемь объектов экологии и 24 кадра эффектов. Контактные линии записаны в каталоге. Площадки и мосты имеют окончания и повторяемую середину. Укороченный последний сегмент корня обрезается, а не сжимается. Варианты задаются хешем идентичности и seed мира; экологические и поведенческие случайные последовательности не расходуются.

## Проверки

```powershell
dotnet build zahlen.sln --no-restore
dotnet run --project Launcher.Pet.Checks --no-restore
dotnet run --project Launcher.Pet.Windows.Checks --no-restore
dotnet run --project Launcher.Pet.Windows.Checks --no-restore -- --render artifacts/sumrak-graphics
```

Проверяются прежние 14 трасс поведения, физика и прерывания, экология и обучение, сохранение вещества, JSON и атомарная запись, защита повреждённых/заблокированных файлов, постоянство руин и жизненный цикл обоев. Новые проверки покрывают весь набор кадров, альфа-маски, ограничение кеша, переключение персонажей, 1080p/1440p/4K/портретную рабочую область, преобразование 96/120/144/192 DPI, переукладку между размерами с сохранением идентичностей, обучения и случайных последовательностей. Отдельная вертикальная сцена проверяет перенос, руку, конфликт с перетаскиванием и прерывание при лазании.

Автономные прогоны достигают всех умений. Для снимков движущегося мира запись идёт каждые 100 мс при шаге симуляции 20 мс; каждый GIF содержит 27 последовательных снимков, включая завершающий жест. Это запись реализации, а не отдельная постановочная анимация.

```powershell
python Launcher.Pet.Windows/Resources/sumrak/export-bundle.py
python Launcher.Pet.Windows/Resources/sumrak/finalize-production.py
python Launcher.Pet.Windows/Resources/sumrak/export-runtime-review.py
```

Экспорт bundle использует установленный `generate2dsprite`; финализация добавляет provenance и автономный HTML-каталог. Экспорт runtime-review выполняется после `--render`. Обновление исходников выполняется через imagegen, затем `process-action.py` с общим профилем; перед повторным экспортом необходимо пересмотреть конкретный клип в движении.

## Завершающая ручная проверка

Проведена проверка HTML-просмотров на светлом, тёмном и шахматном фоне и запись реальных действий renderer; по ней исправлены положения предметов, фазирование и модульные стыки. Не проведена десятиминутная проверка реальных окон рабочего стола с физическим переключением мониторов разного DPI: доступный компьютерный интерфейс этой сессии управляет браузером, а не нативными окнами Windows. Эта проверка остаётся отдельным критерием приёмки: наблюдать 5–10 минут, переместить предметы, прервать перенос, развернуть Launcher, сменить монитор и штатно завершить приложение для проверки исходных обоев.
