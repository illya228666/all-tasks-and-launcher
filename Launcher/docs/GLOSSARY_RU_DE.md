# Glossary / Глоссарий (RU + DE)

- **State**
  - RU: Снимок состояния приложения, который сохраняется между запусками.
  - DE: Gespeicherter Anwendungszustand zwischen Starts.

- **Facade**
  - RU: Упрощённый вход в сложную систему сервисов.
  - DE: Vereinfachter Einstieg in mehrere Services.

- **Domain Model**
  - RU: Модели данных без UI и без файловой логики.
  - DE: Datenmodelle ohne UI- und Dateilogik.

- **Infrastructure**
  - RU: Работа с внешним миром (файлы, JSON, пути).
  - DE: Zugriff auf Aussenwelt (Dateien, JSON, Pfade).

- **Rendering**
  - RU: Построение визуальных элементов по данным.
  - DE: Aufbau visueller Elemente aus Daten.

- **Event Chain**
  - RU: Цепочка от действия пользователя до результата.
  - DE: Kette von Benutzeraktion bis Ergebnis.

- **Dependency**
  - RU: Компонент, от которого зависит другой компонент.
  - DE: Komponente, von der eine andere abhaengt.

- **Single Responsibility**
  - RU: Один файл/класс — одна главная задача.
  - DE: Eine Datei/Klasse — eine Hauptaufgabe.
