# Launcher IO v4 — автономный кубик / autonomer Würfel

Самостоятельная прошивка ESP8266 / NodeMCU 1.0. Функциональность v1–v3 в неё не входит: нет кнопок, потенциометра, PWM, `INDICATOR` или `LEDS`. ESP сам выбирает число **1–6** через `random(1, 7)`, включает соответствующие LED и возвращает результат в WPF-приложение `EspController`.

## Подключение семи LED

Расположите светодиоды как точки на грани кубика:

```text
D1         D2
D3    D5   D6
D7         D8
```

| Пин NodeMCU | GPIO | Позиция | Полярность по умолчанию |
| --- | --- | --- | --- |
| D1 | 5 | верхняя левая | HIGH = включён |
| D2 | 4 | верхняя правая | HIGH = включён |
| D3 | 0 | средняя левая | LOW = включён |
| D5 | 14 | центр | HIGH = включён |
| D6 | 12 | средняя правая | HIGH = включён |
| D7 | 13 | нижняя левая | HIGH = включён |
| D8 | 15 | нижняя правая | HIGH = включён |

Каждому LED нужен свой последовательный резистор, например 1 кОм. У всех LED, кроме D3: `GPIO → резистор → анод LED`, катод → GND. У **D3**: `3.3 V → резистор → анод LED`, катод → D3. Полярности заданы по каждому пину в `BoardConfig.h`.

D3/GPIO0 должен оставаться HIGH при загрузке, D8/GPIO15 — LOW. Такая схема согласована с подтяжками NodeMCU; не подключайте D3 по схеме остальных LED. [Требования загрузки ESP8266](https://arduino-esp8266.readthedocs.io/en/latest/boards.html#boot-messages-and-modes).

| Число | Горящие LED |
| --- | --- |
| 1 | D5 |
| 2 | D1, D8 |
| 3 | D1, D5, D8 |
| 4 | D1, D2, D7, D8 |
| 5 | D1, D2, D5, D7, D8 |
| 6 | D1, D2, D3, D6, D7, D8 |

## Броски и пауза

Первый бросок происходит после запуска платы, затем — каждые **5000 мс**. LED сохраняют результат до следующего броска. Пауза задана в `BoardConfig.h` и реализована через `millis()`; блокирующего `delay()` нет, поэтому плата постоянно отвечает по USB.

В ядре ESP8266 Arduino `random()` использует аппаратный генератор, если не вызван `randomSeed()`. Здесь `randomSeed()` не вызывается. [Реализация в ядре ESP8266](https://github.com/esp8266/Arduino/blob/3.1.2/cores/esp8266/WMath.cpp).

Анимация WPF длится **2100 мс**: подбрасывание, вращение и отскоки, затем показ полученного от ESP числа. При подключении в середине интервала следующий результат может прийти во время анимации: окно заканчивает текущую и воспроизводит последний ожидающий бросок. C# не генерирует финальное число.

## Протокол

115200 baud, 8N1. Команда и ответ заканчиваются LF; CRLF допускается.

```text
HELLO
LAUNCHER_IO 4

POLL
DICE 42 5
```

`DICE <номер_броска> <число>`: номер — беззнаковое 32-битное целое, число — строго 1–6. `POLL` возвращает текущий бросок и **не бросает кубик заново**. `HELLO` также не меняет число, таймер или номер броска. Номер увеличивается даже при повторении числа; после переполнения переходит в 0. После перезапуска платы начинается с 1.

Повтор одного номера не запускает анимацию повторно. При новом USB-соединении текущий бросок показывается заново. Прошивка отвечает `ERR UNKNOWN_COMMAND` на неподдерживаемые команды, `ERR LINE_TOO_LONG` на строки длиннее 31 символа.

## Сборка и запуск

Arduino IDE: плата **NodeMCU 1.0 (ESP-12E Module)**, ядро ESP8266. Откройте `LauncherIoEsp8266V4.ino`, выберите порт и загрузите прошивку. Перед загрузкой нажмите **Trennen** в ESP Controller, чтобы освободить COM-порт.

```powershell
arduino-cli compile --fqbn esp8266:esp8266:nodemcuv2 Launcher.Device/Firmware/LauncherIoEsp8266V4
dotnet build Launcher/Launcher.csproj -c Release
```

Запустите `EspController` из лаунчера. После `HELLO` окно автоматически переключится на кубик; карточки управления v1–v3 скрываются.

DE: Eigenständige v4-Firmware ohne Funktionen der älteren Versionen. Sie würfelt alle fünf Sekunden, zeigt genau so viele LEDs und liefert `DICE <Wurfnummer> <Augenzahl>`. ESP Controller erkennt v4 automatisch und animiert das empfangene Ergebnis.
