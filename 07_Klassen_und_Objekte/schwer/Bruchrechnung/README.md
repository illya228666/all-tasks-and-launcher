# Действия с обыкновенными дробями

Спроектируйте объектно-ориентированную консольную программу для вычислений с двумя дробями. Сначала подготовьте диаграмму классов, затем напишите программу по этой диаграмме.

1. Запросите числитель и знаменатель первой дроби, затем второй.
2. Покажите меню операций. `+` означает сложение, `-` — вычитание, `*` — умножение, `/` — деление, `e` — выход.
3. Выполните выбранную операцию. Если дробь в результате можно сократить, выведите её в сокращённом виде. Покажите числитель и знаменатель отдельно.

Пример сеанса из задания в русском переводе

```text
Действия с дробями
Числитель: 1    Знаменатель: 2
Числитель: 1    Знаменатель: 3

+  Сложение
-  Вычитание
*  Умножение
/  Деление
e  Выход

Выбор: +
Результат
Числитель: 5    Знаменатель: 6
```
