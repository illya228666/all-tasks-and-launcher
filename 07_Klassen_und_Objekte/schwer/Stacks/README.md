# Стек и команды Forth

## Часть 1. Класс `CStack`

Создайте класс `CStack`, который хранит до 50 значений типа `double`. Стек работает по принципу LIFO. Значение, добавленное последним, извлекается первым.

- `push(value)` кладёт значение на вершину. При попытке добавить элемент в заполненный стек выведите сообщение об ошибке.
- `pop()` снимает и возвращает верхнее значение. При попытке извлечь элемент из пустого стека выведите сообщение об ошибке.
- Для проверки создайте пустой стек и добавьте `4`, затем `7`. Два вызова `pop()` должны вернуть `7`, затем `4`.

## Часть 2. Конструктор, арифметика и отладка

- Добавьте конструктор, который принимает массив `double[]` и количество элементов для загрузки. `array[0]` должен оказаться на дне стека.
- Добавьте методы `add()`, `sub()`, `mult()` и `div()`. Каждый снимает два верхних значения, выполняет соответствующую операцию и кладёт результат на вершину.
- Добавьте перегрузки `add(double x)`, `sub(double x)`, `mult(double x)` и `div(double x)`. Каждая снимает одно верхнее значение, выполняет операцию с ним и `x`, затем кладёт результат на вершину.
- Добавьте `out()` для вывода верхнего значения. В исходном примере после `push(5)`, `push(8)`, `push(3)` и `add()` в стеке остаются `5` и `11`, а в комментарии к `out()` указан вывод `5 11`. По формулировке метода вывод вершины в этом примере должен быть `11`.
- Добавьте режим `debugOn()`. После его включения каждый метод, который меняет стек, должен в конце выводить всё его содержимое.

## Часть 3. Класс `CForth`

Создайте класс `CForth`, унаследованный от `CStack`. Добавьте команды `dup()` для дублирования вершины и `swap()` для обмена двух верхних элементов. В тексте программы Forth арифметический знак применяет операцию к двум верхним значениям, а `.` выводит верхнее значение через `out()`.

Добавьте метод `eval`, который выполняет строку команд Forth. Числа в строке попадают в стек, а команды работают с его содержимым. Вызов `eval("3 4 DUP * SWAP DUP * +")` должен вернуть `25`. В примере с выводом `3 4 DUP * SWAP DUP * + .` точка печатает это значение.

Дополнительное задание — снять ограничение в 50 элементов для `CForth`.
